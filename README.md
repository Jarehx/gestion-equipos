# Sistema de Gestion de Equipos Informaticos 

## Funcionalidades

- Guardar, editar y eliminar equipos.
- Persistencia con localStorage.
- Busqueda por titular o marca.
- Filtro por estado:
  - Operativo
  - En Reparacion
  - Descartado
- Contadores de equipos:
  - Total
  - Operativos
  - En reparacion
  - Descartados
- Exportacion de todos los registros a un archivo `equipos.json`.
- Importacion de registros desde un archivo JSON.
- ID unico para cada equipo.
- Fecha y hora de registro.
- Validaciones del formulario.
- Ordenamiento de la tabla.
- Modo oscuro.
- Diseno adaptable para pantallas chicas.
- Confirmaciones con SweetAlert2.

# Archivos

- `index.html`: estructura de la pagina.
- `estilos.css`: diseno y estilos.
- `script.js`: funcionamiento y logica.
- `README.md`: informacion del proyecto.

# Como usarlo

Abrir `index.html` en un navegador.

SweetAlert2 se carga desde un CDN, por lo que necesita conexion a Internet para mostrar las ventanas de confirmacion.
